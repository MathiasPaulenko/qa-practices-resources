# Workshop Retrospective Template QA — Companion

Downloadable files for the [Workshop Retrospective Template: Practical QA](https://qapractices.com/templates/workshop-retrospective-template-qa-teams/) on QAPractices.

## Contents

| File | Purpose |
|---|---|
| `qa-retrospective-workshop.md` | Blank facilitation document: workshop info, timed 90-minute agenda, three prompt banks, metrics review, action items, previous action review, team sentiment and ground rules. |
| `qa-retrospective-workshop-sample.md` | The same document filled after a post-sprint retro for a six-person QA team: metrics with trends, three committed actions, sentiment scores. |

## Usage

1. Copy `qa-retrospective-workshop.md` into your team wiki or shared doc.
2. Fill Workshop Information and pull sprint metrics before the meeting.
3. Run the agenda in order; keep silent writing during data gathering.
4. Cap action items at 3-5 with named owners and due dates.
5. Open the next retro with the Previous Action Items Review table.
