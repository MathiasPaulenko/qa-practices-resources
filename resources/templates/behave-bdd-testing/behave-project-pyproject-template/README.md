# Behave BDD Project pyproject.toml Template

This is a starter `pyproject.toml` for a Behave BDD project. It includes packaging metadata, optional dependency extras (`dev`, `lint`, `test`, `ci`), `behave` paths, `behave-gen` configuration and lint/type-check settings.

## How to use

1. Copy `pyproject.toml` into the root of your project.
2. Replace the bracketed placeholders with your project details.
3. Run `pip install -e ".[dev]"`.
4. Run `behave --dry-run` to validate the suite.
