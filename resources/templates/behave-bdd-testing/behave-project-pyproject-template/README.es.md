# Plantilla pyproject.toml para Proyectos Behave BDD

Este es un `pyproject.toml` de inicio para un proyecto Behave BDD. Incluye metadatos de empaquetado, extras de dependencias opcionales (`dev`, `lint`, `test`, `ci`), paths de `behave`, configuración de `behave-gen` y ajustes de lint y type checking.

## Cómo usar

1. Copiá `pyproject.toml` en la raíz de tu proyecto.
2. Reemplazá los placeholders entre corchetes por los datos de tu proyecto.
3. Corré `pip install -e ".[dev]"`.
4. Corré `behave --dry-run` para validar la suite.

## Guía completa

Consultá la [plantilla de QAPractices](https://qapractices.com/es/templates/behave-project-pyproject-template) para explicaciones, mejores prácticas y un ejemplo completado.
