# Accessibility Audit Report Template — Companion

Downloadable files for the [Accessibility Audit Report Template](https://qapractices.com/templates/accessibility-audit-report-template/) on QAPractices.

## Contents

| File | Purpose |
|---|---|
| `accessibility-audit-report.md` | Blank audit report: header, executive summary, scope, methodology, findings summary and detail blocks, remediation roadmap, sign-off and evidence log. |
| `accessibility-audit-report-sample.md` | The same report filled end-to-end after a fictional WCAG 2.2 Level AA audit of the ClearPath Insurance quote portal — 1 critical, 2 major, 3 minor findings with a P0-P3 roadmap. |

## Usage

1. Copy `accessibility-audit-report.md` into your project docs or wiki.
2. Fill Sections 1-4 before and while you audit: scope and methodology first, never from memory afterwards.
3. Write one finding block per issue in Section 6 — group repeated instances under a single finding with an occurrence count.
4. Fill the findings summary (Section 5) last so the counts match Section 6 exactly.
5. Use `accessibility-audit-report-sample.md` as the reference for tone, level of detail and severity calls.

The report structure follows WCAG-EM. Map every finding to a specific [WCAG 2.2 success criterion](https://www.w3.org/WAI/WCAG22/quickref/) with its level.
