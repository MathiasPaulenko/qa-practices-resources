# Checklist de Checkout E-commerce

Checklist imprimible e importable para validar el flujo completo de checkout e-commerce antes de un release o tras cambios en el flujo de compra.

## Contenido

-  — la checklist completa en Markdown (53 ítems en 9 secciones, cada uno con nivel de riesgo).
-  — la misma checklist en JSON estructurado para importar en herramientas de gestión de tests.

## Secciones

Gestión de Carrito · Autenticación de Usuario · Envío y Fulfillment · Cálculo de Impuestos · Descuentos y Promociones · Procesamiento de Pagos · Prevención de Fraude · Confirmación de Pedido · Casos Edge y Manejo de Errores

## Uso

- Importa el JSON en tu herramienta de gestión de tests o conviértelo al formato de tu tracker.
- Cada ítem lleva un campo  (, , ) para priorizar el orden de ejecución.
