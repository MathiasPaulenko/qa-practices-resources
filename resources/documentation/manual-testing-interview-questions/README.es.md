# Entrevista de Testing Manual: Top 50 Preguntas y Respuestas — Companion

Este companion es una versión imprimible y legible por máquina de la [guía de Entrevista de Testing Manual](https://qapractices.com/es/documentation/manual-testing-interview-questions) en QA Practices.

## Contenidos

- `manual-testing-interview-questions.json` — Las 50 preguntas y respuestas en formato JSON, aptas para flashcards o apps de repetición espaciada.
- `README.es.md` — Este archivo.

## Formato JSON

```json
{
  "title": "Entrevista de Testing Manual: Top 50 Preguntas y Respuestas",
  "questions": [
    {
      "id": "Q1",
      "category": "Fundamentos",
      "question": "¿Qué es el testing manual y por qué todavía lo necesitamos?",
      "answer": "..."
    }
  ]
}
```

## Cómo usar

1. Importá `manual-testing-interview-questions.json` en Anki, Quizlet o cualquier app de flashcards que soporte JSON.
2. Usá el campo `category` para filtrar por tema.
3. Imprimí `README.es.md` o la guía fuente para estudiar offline.
