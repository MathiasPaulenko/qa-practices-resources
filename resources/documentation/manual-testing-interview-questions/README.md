# Manual Testing Interview: Top 50 Questions & Answers — Companion

This companion is a printable and machine-readable version of the [Manual Testing Interview guide](https://qapractices.com/documentation/manual-testing-interview-questions) on QA Practices.

## Contents

- `manual-testing-interview-questions.json` — All 50 questions and answers in JSON format, suitable for flashcards or spaced-repetition apps.
- `README.md` — This file.

## JSON format

```json
{
  "title": "Manual Testing Interview: Top 50 Questions & Answers",
  "questions": [
    {
      "id": "Q1",
      "category": "Fundamentals",
      "question": "What is manual testing and why do we still need it?",
      "answer": "..."
    }
  ]
}
```

## How to use

1. Import `manual-testing-interview-questions.json` into Anki, Quizlet, or any flashcard app that supports JSON.
2. Use the `category` field to filter by topic.
3. Print `README.md` or the source guide for offline study.
