# Proyecto Ejemplo Completo de Pytest

Este proyecto complementario acompaña la [Guía Completa de Pytest](https://qapractices.com/es/documentation/pytest-complete-guide/) en QAPractices.

El código bajo `pytest-complete/` es un proyecto de Python ejecutable que refleja los ejemplos de la guía: fixtures, parametrización, markers, mocks, cobertura y CI/CD.

## Inicio rápido

```bash
cd pytest-complete
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pytest
```
