# Pytest Complete Example Project

This companion project supports the [Pytest Complete Guide](https://qapractices.com/documentation/pytest-complete-guide/) on QAPractices.

The code under `pytest-complete/` is a runnable Python project that mirrors the examples in the guide: fixtures, parametrization, markers, mocking, coverage and CI/CD.

## Quick start

```bash
cd pytest-complete
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pytest
```
