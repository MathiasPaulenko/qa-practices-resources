# Session Charter

> Copy this file once per session. A charter should fill 60-90% of a 90-minute
> session. If you cannot state the risk, the charter is not ready.

## Mission

Explore: [area/feature under test]
With: [resources, tools, techniques]
To discover: [information goal or risk]

- Build / version:
- Environment:
- Related risks or recent changes:

## Sizing

- [ ] Estimated to fill 60-90% of one session
- [ ] Not a test case — no step-by-step expected results
- [ ] Has a technique or approach, not just an area
- [ ] Has a risk or information goal, not just "find bugs"
