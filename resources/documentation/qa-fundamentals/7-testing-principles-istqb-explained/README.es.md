# 7 Principios de Testing ISTQB Explicados — Companion (ES)

Recurso companion para [7 Principios de Testing ISTQB Explicados](https://qapractices.com/es/documentation/7-testing-principles-istqb-explained).

## Contenido

- `src/equivalence_classes.py` — Validación de edad dividida en clases de equivalencia (Principio 4: testing exhaustivo es imposible)
- `src/risk_score.py` — Matriz de riesgo: probabilidad × impacto para priorización de features (Principio 3: testing basado en riesgo)

## Requisitos

- Python 3.12+

## Uso

```bash
python src/equivalence_classes.py
python src/risk_score.py
```

Son implementaciones de referencia para los conceptos explicados en la guía.
