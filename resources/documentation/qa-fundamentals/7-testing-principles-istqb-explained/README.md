# 7 Testing Principles ISTQB Explained — Companion

Companion resource for [7 Testing Principles ISTQB Explained](https://qapractices.com/documentation/7-testing-principles-istqb-explained).

```bash
python src/equivalence_classes.py
python src/risk_score.py
```
