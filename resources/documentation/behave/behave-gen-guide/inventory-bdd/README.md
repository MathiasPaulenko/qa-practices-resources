# inventory-bdd

A Behave BDD project generated by [behave-gen](https://github.com/MathiasPaulenko/behave-gen) for the QAPractices guide [Behave Project Scaffolding with behave-gen](https://qapractices.com/documentation/behave-gen-guide/).

## Quickstart

```bash
pip install -e .
behave --dry-run
behave
```

## Layout

```
features/          Gherkin .feature files
features/steps/    Step definitions
environment.py     Behave hooks (before/after scenario, etc.)
behave.toml        Behave configuration
pyproject.toml     Project metadata and behave-gen config
```

## Adding content

```bash
behave-gen add feature login
behave-gen add steps --lib auth
```
