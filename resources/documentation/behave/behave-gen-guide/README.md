# Behave-gen Scaffolded BDD Example

This folder contains a runnable Behave BDD project that was scaffolded with [behave-gen](https://github.com/MathiasPaulenko/behave-gen) and mirrors the example from the QAPractices guide [Behave Project Scaffolding with behave-gen](https://qapractices.com/documentation/behave-gen-guide/).

It shows the result of `behave-gen init`, `behave-gen add feature` and `behave-gen add steps --lib auth`. The generated placeholder feature was replaced with a real `login.feature` that uses the auth step library.

## Project structure

```text
inventory-bdd/
├── README.md
├── pyproject.toml
├── behave.toml
├── environment.py
└── features/
    ├── login.feature
    └── steps/
        └── auth_steps.py
```

## What it demonstrates

- `pyproject.toml` and `behave.toml` come from `behave-gen init`.
- `environment.py` contains the empty lifecycle hooks generated by `behave-gen`.
- `features/login.feature` replaces the placeholder with three concrete scenarios about session authentication.
- `features/steps/auth_steps.py` was added with `behave-gen add steps --lib auth` and provides in-memory session helpers.

## Run locally

```bash
cd inventory-bdd
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -e .
behave
```

All three scenarios should pass.

## Regenerate from scratch

```bash
pip install behave-gen
behave-gen init inventory-bdd
cd inventory-bdd
behave-gen add feature login
behave-gen add steps --lib auth
```

Then replace `features/login.feature` with the feature file from this folder.
