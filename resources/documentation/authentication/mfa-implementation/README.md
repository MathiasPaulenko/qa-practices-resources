# MFA Implementation Testing Guide — Companion Scripts

Companion scripts for the [MFA Implementation Testing Guide](https://qapractices.com/documentation/mfa-implementation/) on QAPractices.com.

## Scripts

| Script | Language | What it does |
| --- | --- | --- |
| `scripts/totp-helpers.py` | Python 3.10+ | Generate current, previous and next-step TOTP codes from a seeded secret using pyotp 2.12.1. |
| `scripts/lockout-probe.py` | Python 3.10+ | Hammer the MFA verify endpoint with wrong codes and assert the verifier rate-limits or locks the account. Uses requests 2.32.3. |
| `scripts/totp-login.spec.ts` | TypeScript | Playwright spec that completes the OTP challenge with a code generated by otplib 13.6, plus the replay test. |
| `scripts/webauthn-virtual-authenticator.spec.ts` | TypeScript | Playwright spec that registers a virtual WebAuthn authenticator via Chrome DevTools Protocol and runs an assertion ceremony. |

## Requirements

- Python 3.10+
- `pip install pyotp==2.12.1 requests==2.32.3`
- Node 20+, `@playwright/test` 1.65.1, `otplib` 13.6.0

## Usage

```bash
# 1. Generate TOTP codes for test fixtures
python scripts/totp-helpers.py

# 2. Probe the verifier for lockout / rate limiting
python scripts/lockout-probe.py

# 3. Run the Playwright specs (staging only, seeded test users)
export TEST_TOTP_SEED=JBSWY3DPEHPK3PXP
export TEST_USER_PASSWORD=<test-password>
npx playwright test scripts/totp-login.spec.ts
npx playwright test scripts/webauthn-virtual-authenticator.spec.ts
```

## Notes

- All URLs point at `staging.qapractices.com` placeholders — replace them with your own test environment.
- Never run `lockout-probe.py` against production or shared environments; it will lock the test account on purpose.
- The WebAuthn spec requires Chromium (CDP `WebAuthn.addVirtualAuthenticator`); it does not work on Firefox or Safari.
