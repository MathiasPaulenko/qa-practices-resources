# Prompt de IA: Generar archivos feature de Behave BDD

Este es un prompt listo para copiar y generar archivos `.feature` de Behave BDD a partir de user stories y criterios de aceptación.

## Archivos

- `prompt.md` — el prompt completo con ejemplo de entrada, salida, mejores prácticas, errores comunes y variaciones.

## Cómo usar

1. Abrí `prompt.md`.
2. Copiá el texto dentro de `## The Prompt`.
3. Completá los placeholders con tu dominio, feature, user story y criterios de aceptación.
4. Pegalo en tu LLM y revisá el archivo feature generado antes de commitear.

## Recurso completo

Para la versión renderizada con metadatos y recursos relacionados, consultá la [página del prompt en QAPractices](https://qapractices.com/es/prompts/ai-prompt-behave-feature-generation).
