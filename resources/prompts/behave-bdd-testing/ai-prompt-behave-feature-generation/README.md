# AI Prompt: Generate Behave BDD Feature Files

This is a ready-to-copy prompt for generating Behave BDD `.feature` files from user stories and acceptance criteria.

## Files

- `prompt.md` — the full prompt with example input, output, best practices, common mistakes and variations.

## How to use

1. Open `prompt.md`.
2. Copy the text inside `## The Prompt`.
3. Fill in the placeholders with your domain, feature, user story and acceptance criteria.
4. Paste it into your LLM and review the generated feature file before committing.
