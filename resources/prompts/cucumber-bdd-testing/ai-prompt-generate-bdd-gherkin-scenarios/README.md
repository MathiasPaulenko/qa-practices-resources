# AI Prompt: Generate BDD Gherkin Scenarios

Ready-to-copy prompt that turns a user story plus acceptance criteria into a Gherkin `.feature` file — happy paths, negatives, edge cases and a Scenario Outline.

## Files

- `prompt.md` — the full prompt with the filled example input.
- `password-reset.feature` — the feature file the prompt produces for that input.

## How to use

1. Open `prompt.md` and copy the text inside `## The Prompt`.
2. Replace the bracketed placeholders with your user story, acceptance criteria, business rules and BDD runner.
3. Paste it into your LLM and review the generated scenarios before committing — scenario names first, steps second.
4. Compare your output with `password-reset.feature` to sanity-check structure, tagging and declarative phrasing.
