# AI Prompt: QA Interview Preparation — Companion

Companion files for the [AI Prompt: QA Interview Preparation](https://qapractices.com/prompts/ai-prompt-qa-interview-preparation) resource.

## Files

| File | Purpose |
| --- | --- |
| `prompt-template.txt` | The full interview preparation prompt, ready to copy into an LLM. |
| `example-input.txt` | A filled-in context: Senior QA at a mid-size fintech, Playwright/Postman stack, 60-minute technical round. |
| `example-output.md` | A realistic output fragment: two questions with model answers, interviewer's lens, follow-ups and red flags. |

## Usage

1. Copy `prompt-template.txt` into your LLM.
2. Fill the context block with the real role, stack and interview format — paste the actual job description into the stack and focus fields for the best fit.
3. Compare the response shape with `example-output.md`; if a section is missing, ask for that numbered output again.
4. Drill 4-6 questions per focus area instead of asking for every category at once.
5. For the final week, append the mock-interview variation so the model scores your answers one question at a time.
