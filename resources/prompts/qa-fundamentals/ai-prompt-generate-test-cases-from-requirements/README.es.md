# Prompt de IA: generar casos de prueba desde requisitos — Companion

Archivos companion para el [Prompt de IA: generar casos de prueba desde requisitos](https://qapractices.com/es/prompts/ai-prompt-generate-test-cases-from-requirements).

## Archivos

| Archivo | Propósito |
| --- | --- |
| `prompt-template.txt` | Plantilla de prompt lista para copiar y pegar en cualquier LLM. |
| `example-input.txt` | Input de ejemplo para una feature de registro de usuario. |
| `example-output.csv` | Output de ejemplo con 7 casos de prueba en formato CSV para importar. |

## Uso

1. Copiá `prompt-template.txt` en tu LLM (ChatGPT GPT-4o, Claude 3.5 Sonnet, GitHub Copilot).
2. Reemplazá los placeholders entre corchetes con los detalles de tu requisito.
3. Pegá tu requisito o historia de usuario donde se indica.
4. Ejecutá el prompt y revisá el output.
5. Importá `example-output.csv` en Jira, TestRail o Zephyr como formato de referencia.

## Requisitos

- Cualquier LLM (ChatGPT GPT-4o, Claude 3.5 Sonnet, GitHub Copilot, o LLM local)
