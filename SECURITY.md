# Security Policy

## Supported versions

This is a companion resource repository for [qapractices.com](https://qapractices.com). We support the latest version on the `main` branch. Older commits are not actively maintained.

## Reporting a vulnerability

If you discover a security issue in any resource, workflow or file in this repository, please report it responsibly.

- **Non-sensitive issues:** open a public issue with the `security` label.
- **Sensitive issues:** email `contact@qapractices.com` with a clear description of the problem and, if possible, steps to reproduce it.

> The security contact email should be updated if it changes. If you are unsure whether an issue is sensitive, use the private email.

## What to expect

- We will acknowledge receipt as soon as possible, usually within a few days.
- We will investigate the report and let you know the outcome.
- Once the issue is resolved, we will disclose it transparently and credit the reporter unless they prefer to remain anonymous.

## Security best practices for contributors

- Do not commit secrets, API keys, passwords or personal access tokens.
- Do not include real user data in examples.
- Keep example dependencies pinned to known, stable versions.
- If you add a workflow that requires permissions, follow the principle of least privilege.
